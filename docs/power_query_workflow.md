# Power Query Workflow

1. Get Data → Import laptop CSV
2. Promote First Row as Headers
3. Set appropriate data types
4. Rename required columns
5. Create Custom Column: `TotalStorage_GB`
6. Create Custom Column: `ScreenResolution`
7. Create analysis columns: `PriceBand`, `WeightBand`, `RAM_Band`, `Display_Feature`
8. Close & Load cleaned data to Excel

The workbook contains the live Power Query work and a `Power_Query` sheet documenting the workflow.
